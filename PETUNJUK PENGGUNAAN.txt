============================================================
1. SEBELUM MENJALANKAN eduXid
============================================================

Langkah Awal:
- Pastikan Anda memiliki eduXid-DISTRIBUSI-.zip.
- Ekstrak eduXid-DISTRIBUSI-.zip di drive manapun yang Anda inginkan (klik kanan --> extract).
- Dalam folder eduXid-DISTRIBUSI-, terdapat folder eduXid, system, dan php, serta file: eduXid.exe dan PETUNJUK PENGGUNAAN.txt. eduXidAutoUpdate.exe dan eduXidUpdater.exe berada di subfolder system. File BAT/CMD dan helper auto-update tetap disertakan untuk pemasangan otomatis tanpa PowerShell.
- Jangan mengubah file apapun termasuk .env, database, APP_KEY, token sinkronisasi, atau file sistem eduXid secara manual kecuali untuk perbaikan teknis yang memang diarahkan.

============================================================
2. LOGIN PERTAMA
============================================================

1. Jalankan eduXid.exe.muncul jendela eduXid Sync Engine dan eduXid Sync Daemon, biarkan saja dua jendela ini, jangan ditutup selama Anda bekerja menggunakan eduXid.
2. Muncul halaman login pada browser.
3. Masuk menggunakan akun Admin.

   username : admin
   password : admin123
   (Password bisa diganti pada menu profil admin)

4. Setelah login, buka halaman Dasbor.

Pada penggunaan pertama, eduXid dapat berada dalam MODE SETUP karena data sekolah belum tersedia.

============================================================
3. SINKRON VIA API DAPODIK (DISARANKAN)
============================================================

Untuk setup awal menggunakan DAPODIK, pastikan eduXid dijalankan di laptop yang sudah terinstal aplikasi DAPODIK. Masukkan data:

1. NPSN sekolah
2. Kode Token yang diperoleh dari menu Pengaturan Dapodik -> Web Service -> Tambah aplikasi eduXid -> copy/catat kode Token yang muncul.
3. Tekan tombol sinkron sekarang.

============================================================
4. IMPOR MANUAL DATA EXCEL
============================================================

Jika sekolah tidak menggunakan Dapodik, Anda dapat melakukan impor Excel menggunakan template resmi eduXid yang sudah disediakan.

Urutan impor:

1. Sekolah
2. GTK
3. Kelas
4. Murid
5. Mata Pelajaran
6. Pembelajaran

Sebelum impor:
- Jangan mengubah nama kolom template.
- Jangan menghapus kolom wajib.
- Pastikan NISN siswa benar.
- Pastikan NIP/NIK/NUPTK GTK benar.
- Pastikan nama kelas konsisten.
- Pastikan mata pelajaran sudah tersedia sebelum mengimpor pembelajaran.

Setelah setiap impor, periksa hasilnya sebelum lanjut ke tahap berikutnya.

============================================================
5. MEMERIKSA DATA GTK
============================================================

Buka menu GTK.

Periksa:
- Nama GTK
- NIP
- NIK
- NUPTK jika ada

============================================================
6. MEMERIKSA DATA MURID
============================================================

Buka menu Murid.

Periksa:
- Nama murid
- NISN
- Jenis kelamin
- Kelas/Rombel
- Data peserta didik lainnya
- Anda bisa menambahkan data murid baru di sini

NISN digunakan sebagai identitas penting siswa pada:
- PWA Siswa
- Ujian
- Nomor peserta ujian
- LJK
- Sinkronisasi perangkat siswa

============================================================
7. MEMERIKSA KELAS / ROMBEL
============================================================

Buka menu Kelas.

Pastikan:
- Semua rombel reguler sudah tersedia.
- Tingkat kelas benar.
- Wali kelas terhubung jika tersedia.
- Jumlah siswa per rombel sesuai.

Data kelas digunakan pada:
- Pembelajaran
- LMS
- Buku Nilai
- Rapor
- Administrasi Ujian
- Kapasitas ruang ujian

============================================================
8. MEMERIKSA MATA PELAJARAN
============================================================

Pastikan semua mata pelajaran sekolah sudah tersedia dan tidak ada nama mapel yang terduplikasi karena perbedaan penulisan.

============================================================
9. MEMERIKSA PENUGASAN MENGAJAR
============================================================

Buka menu Pembelajaran.

Hubungkan:
GTK + Mata Pelajaran + Kelas/Rombel

Penugasan Mengajar menentukan guru yang berhak mengakses:
- ATP
- LMS
- Bank Soal
- Paket Ujian
- Buku Nilai
- Nilai Akhir

Pastikan tidak ada salah guru, salah mapel, atau salah kelas.

11. MENYIAPKAN eduXid CLOUD
============================================================

Data utama tetap berada pada instalasi eduXid masing-masing.

Pastikan koneksi Cloud normal sebelum pairing perangkat.

Hubungi pengembang eduXid untuk mendapatkan kode Cloud Setup sekolah Anda.

============================================================
23. UPDATE eduXid
============================================================

eduXid menggunakan sistem updater terpusat. system\eduXidAutoUpdate.exe adalah komponen Auto-Update Windows, sedangkan system\eduXidUpdater.exe untuk patch manual. eduXid.exe tetap di root. Pendaftaran pembaruan dilakukan otomatis saat launcher eduXid berjalan; pemeriksaan Cloud setiap 24 jam, pemasangan otomatis saat aman, tanpa PowerShell. Bila komponen EXE belum tersedia dari hasil kompilasi resmi, paket distribusi tidak boleh diterbitkan.

Update dapat mencakup:
- core
- school
- teacher

Pastikan sinkronisasi selesai sebelum memasang update.

Jika ada ujian aktif, jangan memaksa restart atau instal update.

PENGGUNAAN TIGA EXECUTABLE (DISTRIBUSI 2026-10-09)
=================================================
Hanya eduXid.exe berada pada root (jalankan aplikasi).
Dua executable lainnya berada di system: system\eduXidUpdater.exe
(pembaruan manual) dan system\eduXidAutoUpdate.exe
(pendaftaran pembaruan otomatis).

Cukup buka eduXid.exe. Launcher yang dikompilasi dari source baru
menjalankan system\eduXidAutoUpdate.exe otomatis. Untuk eduXid.exe lama,
Laravel menyediakan jalur cadangan pendaftaran saat aplikasi dibuka.
Task Scheduler bangun setiap 15 menit; cek Cloud hanya saat jatuh tempo
24 jam. Instalasi patch otomatis hanya dilakukan saat kondisi aman.

Helper CMD/PHP utama ditempatkan di system\, sementara helper internal
berada dalam system\update. Jangan menghapus kedua folder tersebut.
Setelah memindahkan executable, kompilasi ulang EXE dari BAT terbaru.
Executable lama yang masih mengarah ke helper root harus diganti.
Tidak menggunakan PowerShell. Pada komputer Windows pembatasan izin
Task Scheduler dapat menunda registrasi; lihat .eduxid-updater\task-bootstrap.log.
